用户要求计算夏普比率。需要给出计算过程。

给定：
- 月度收益率算术均值 R_p = 1.0% = 0.01
- 月度收益率标准差 sigma = 4.5% = 0.045
- 月无风险收益率 R_f = 0.2% = 0.002

用月度超额收益的算术均值计算月度夏普比率：
月度超额收益算术均值 = R_p - R_f = 0.01 - 0.002 = 0.008 = 0.8%
月度夏普比率 = 0.008 / 0.045 = 0.177777... ≈ 0.1778

按 sqrt(12) 法则年化：
年化夏普 = 月度夏普 * sqrt(12) = 0.177777... * 3.464101615... = ?

0.1777777778 * 3.4641016151 = 
0.1777777778 * 3.4641016151
= (0.008/0.045)*sqrt(12)
= 0.008 * sqrt(12) / 0.045
sqrt(12)=3.4641016151377544
0.008*3.4641016151377544 = 0.027712812921102035
/0.045 = 0.6158402871356008

约 0.6158，即约 0.62。

需要注意：如果年化超额收益用算术均值*12 = 9.6%，年化波动率 = 4.5%*sqrt12 = 15.588%，则年化夏普 = 9.6/15.588 = 0.6158，一致。
