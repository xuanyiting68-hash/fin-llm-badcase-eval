## 问题

我在做毕业论文，用 OLS 回归股票日收益率，发现残差存在明显的异方差。请问：OLS 系数估计还是无偏的吗？t 检验还能用吗？应该怎么处理？

## 回答

# 一、系数还是无偏的吗？——是的

OLS 的无偏性和一致性只依赖于核心假定：

- 模型设定正确（线性、随机抽样、无完全共线性）
- **关键：零条件均值 E(u|X) = 0（外生性）**

异方差违反的是同方差假定 Var(u|X) = σ²，它**不影响无偏性和一致性**。所以：

- ✅ 系数估计仍然无偏、一致，点估计结果可以直接用
- ❌ 但 OLS 不再是 BLUE（高斯-马尔可夫定理失效），即不再是方差最小的线性无偏估计量，存在更高效的估计方法

⚠️ 一个提醒：如果异方差是**模型误设**（遗漏变量、函数形式错误）的"症状"，外生性可能同时被破坏，那无偏性才有问题。不过对股票日收益率来说，异方差通常就是**波动聚集**（volatility clustering）的天然特征，属于正常现象。

# 二、t 检验还能用吗？——默认的不行

经典标准误的公式 σ²(X′X)⁻¹ 是在同方差假定下推导的。异方差下真实的系数方差是：

$$(X'X)^{-1} X'\Omega X (X'X)^{-1}$$

用错误的标准误会导致：

- t 统计量不再服从 t 分布（大样本下也不渐近正态）
- p 值、置信区间都不可信，可能得到**虚假的显著性**（也可能拒绝不足，方向不确定）

**但注意**：只要把标准误换成异方差稳健标准误，t 检验（大样本下）就重新有效了。所以不是"不能做 t 检验"，而是"不能用原来的标准误做 t 检验"。

# 三、怎么处理？

**方案 1：OLS + White 稳健标准误（最常用）**

系数不动，只修正推断，这是实证研究的标准做法：

```stata
* Stata
reg y x1 x2 x3, robust
```

```r
# R
library(sandwich); library(lmtest)
fit <- lm(y ~ x1 + x2, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC3"))
```

```python
# Python (statsmodels)
sm.OLS(y, X).fit(cov_type='HC3')
```

**方案 2：根据你的数据结构选择更合适的方法（重要）**

| 数据结构 | 推荐 |
|---|---|
| 单只股票的日收益（时间序列） | **Newey-West HAC 标准误**（同时处理异方差+自相关，收益率常有一定自相关） |
| 多只股票的 panel | **按公司聚类的标准误**；若担心市场整体冲击，用公司+时间**双向聚类** |

**方案 3：对方差显式建模**

- **WLS/FGLS**：若能正确设定方差函数，效率比 OLS 高（但设错了反而更糟）
- **GARCH 族模型**：日收益率的波动聚集是它的"主场"，可以在均值方程后接 GARCH(1,1) 误差项，顺带刻画波动动态。如果论文篇幅允许，作为稳健性检验很加分

# 论文中的标准处理流程

1. **先报告检验**：Breusch-Pagan 或 White 检验的结果写进论文，证明确实存在异方差
2. **说明理论依据**：写一句"异方差不影响 OLS 系数的无偏性与一致性，但会使常规标准误失效，故本文采用稳健标准误进行统计推断"
3. **主回归**用稳健标准误（时间序列用 Newey-West，面板用聚类）
4. **稳健性检验**：对比常规标准误 vs 稳健标准误下显著性的变化，或用 GARCH/WLS 重估一遍

另外注意：稳健标准误是**大样本性质**，日收益率数据通常几百上千个观测，完全够用；样本偏小时优先选 HC3。

一句话总结：**系数照用，标准误换稳健的，检验照常做。**
