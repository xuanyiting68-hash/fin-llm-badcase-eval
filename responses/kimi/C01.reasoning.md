# C01 · Kimi · 思考过程

用户问的是一道财务分析题。需要判断A股公司业绩是否大幅改善并说明理由。关键数据：归母净利润2.7亿，同比增长80%；扣非归母净利润1.2亿，同比下降15%；出售子公司获得投资收益1.6亿。

需要说明：表面归母净利润大增80%，但增长主要来自非经常性损益（出售子公司一次性投资收益1.6亿）。扣非后净利润只有1.2亿且同比下降15%，说明主营业务/持续经营盈利能力没有改善反而下滑。还要分析数字勾稽：归母净利2.7 - 扣非1.2 = 非经常性损益约1.5亿，和出售子公司投资收益1.6亿大体匹配（考虑所得税、少数股东等影响），说明利润增量几乎全部由一次性资产处置贡献。去年同期归母净利润 = 2.7/1.8 = 1.5亿；今年扣非1.2，去年扣非 = 1.2/0.85 ≈ 1.4118亿。剔除出售收益影响后，今年持续经营利润可能约1.2亿，低于去年扣非约1.41亿，也低于去年归母1.5亿。若把今年出售子公司收益1.6亿从归母净利润中剔除（粗略，税前/税后需注意），持续经营归母利润约1.1亿（2.7-1.6），同比下滑约26.7%（相对去年归母1.5亿）。如果严格按扣非口径已经剔除，则同比下降15%。结论：不能认定为大幅改善；属于“报表利润高增、经营质量下滑/依赖一次性收益”。应看扣非、经营现金流、毛利率、营收、行业、持续经营假设、资产处置是否经常性化、是否粉饰报表/保壳等。

需要注意表述：出售子公司投资收益通常计入非经常性损益，但企业所得税法下股权转让收益应纳税；题目说获得投资收益1.6亿元，可能是税前利润口径；扣非归母与归母差1.5亿，不是正好1.6，可能因税费、少数股东损益、其他非经常项目等。可以提一句不要求精确勾稽。

还要给投资者结论：关注利润质量和可持续性；估值时应以扣非净利润或正常化利润为基础，剔除一次性收益；若主营业务收入和扣非净利下降，说明核心经营承压。年报归母增长80%容易误导。若公司出售的是重要盈利子公司，未来利润还可能下台阶；若出售亏损资产，则可能减负，但题中扣非仍下降，需看被出售子公司的经营贡献和行业。一般出售子公司获得投资收益1.6亿，说明标的可能有增值；但处置后合并范围变化会影响未来收入利润。若该子公司原本贡献利润，则未来持续利润更低；若原本亏损，则出售有利于止损，但扣非同比下降仍说明剩余业务不佳。

答案结构：先给结论，后列理由：
1. 归母净利高增但非经常损益占比高。非经常性损益约1.5亿（2.7-1.2），占归母净利润约56%；出售子公司收益1.6亿超过非经常性损益净额，是利润高增主因。一次性不可持续。
2. 扣非后净利1.2亿，同比降15%，更能反映主营持续经营，说明核心盈利恶化。去年扣非约1.41亿，今年减少约0.21亿。
3. 简单还原：去年归母1.5亿。今年若剔除出售收益约1.6亿，持续经营归母约1.1亿，同比下滑约27%；与扣非下降方向一致。
4. 还需结合营收、毛利率、经营现金流、应收账款/存货、负债、资产减值、被出售子公司是否为利润来源、交易定价公允性、是否关联方、是否有粉饰/保壳动机。经营现金流若不佳，利润质量更差。

结论：不是实质性大幅改善，而是依靠资产处置的一次性收益做高当期利润；业绩质量偏弱，真实经营可能下滑。若必须表述：归母净利润“账面大幅改善”，持续经营能力“未改善甚至恶化”。

需要确保不透露工具/思考。用中文回答。语气专业。现在直接给出最终。答案适度详细。

检查数字：归母同比增长80% => 去年归母=2.7/(1+0.8)=1.5。扣非同比降15% => 去年扣非=1.2/(1-0.15)=1.4117647059。非经常性损益今年=1.5亿，占归母=55.6%。去年非经常=1.5-1.4118=0.0882亿。也就是说去年利润几乎全是扣非，今年靠非经常。若把出售子公司投资收益1.6亿视作非经常项目，扣非差额1.5与1.6差0.1，可能其他非经常项目/税/少数股东。提及“大致对应”。

还要注意：出售子公司获得投资收益1.6亿，在合并报表中，丧失控制权产生的投资收益可能包括股权处置对价与享有净资产份额差额，以及剩余股权公允价值重估、其他综合收益转入等。这个通常列入非经常性损益。无须复杂。

最终答案应明确“业绩是否大幅改善”——判断为：否，不宜认定。可以分“会计利润”和“经营实质”。如果问法从财报公布，可能容易让人误以为大幅改善，需要纠偏。
