# D04 · Kimi · 思考过程

用户问的是一个关于融资融券维持担保比例的计算题。需要仔细计算。

题目：客户信用账户里有自有资金50万元，又融资50万元，全部买入同一只股票（合计市值100万元）。券商规定：维持担保比例 =（现金 + 信用账户证券市值）÷ 融资负债，警戒线150%，平仓线130%。不考虑利息和费用。

初始：
- 自有资金（现金）50万，融资50万，全部买入股票。买入后现金为0？题目说"客户信用账户里有自有资金50万元，又融资50万元，全部买入同一只股票（合计市值100万元）"。维持担保比例分子=现金+信用账户证券市值。全部买入后现金=0，证券市值=100万，融资负债=50万。初始维持担保比例=100/50=200%。

(1) 股价下跌多少触及警戒线150%、平仓线130%。

设股价下跌比例为 x（即市值变为 100*(1-x) 万）。融资负债仍为50万（不考虑利息）。现金=0。

维持担保比例 = 100*(1-x) / 50 = 2*(1-x)。

警戒线150%：2*(1-x)=1.5 => 1-x=0.75 => x=0.25 =25%。
平仓线130%：2*(1-x)=1.3 => 1-x=0.65 => x=0.35=35%。

所以股价下跌25%触及警戒线，下跌35%触及平仓线。

需要说明：这里指从买入价下跌的幅度。也可以给出对应市值：警戒线时市值75万，平仓线时市值65万。

(2) 若维持担保比例刚好跌到130%，客户希望恢复到150%。

此时状态：市值=65万，融资负债=50万，现金=0。维持担保比例=65/50=130%。

如果追加现金：设追加现金 C 万元。追加后分子=65 + C（证券市值仍为65，现金C），分母=融资负债50万（追加现金不偿还融资，只是放入账户）。要求 (65+C)/50 = 1.5 => 65+C =75 => C=10万元。

注意：追加现金后，分子是现金+证券市值= C + 65。对的。需要追加10万现金。

如果卖出股票偿还融资：设卖出市值 S 万元股票，所得资金偿还融资负债。假设卖出价格即为当前市价（已经跌了35%之后的价格），卖出 S 万市值，则证券市值变为 65 - S，融资负债变为 50 - S（用卖券所得偿还融资），现金仍为0（卖出资金直接还款）。维持担保比例 = (65 - S)/(50 - S) = 1.5。

解：65 - S = 1.5*(50 - S) = 75 - 1.5 S。
65 - S = 75 - 1.5 S
移项：-S +1.5 S = 75 -65
0.5 S =10
S=20 万元。

检验：卖出20万后，市值45万，负债30万，比例=45/30=150%。正确。

需要注意一个细节：卖出股票偿还融资，是否会产生现金？在信用账户中，卖出证券所得资金优先偿还融资负债（如果是融资买入的证券，卖出所得通常直接还款）。题目说"卖出股票偿还融资"，所以卖券款用于偿还融资负债。因此分子减少S，分母也减少S。正确。

但是要小心：维持担保比例分子=现金+证券市值。若卖出股票但资金留在账户不偿还融资，则分子不变（证券市值减少S，现金增加S），比例不变；但题目明确"卖出股票偿还融资"，所以分母减少。这个区别值得指出。

另外，需要确认追加现金恢复：若客户追加现金但不还款，则负债不变，分子增加。如果客户追加现金并用现金偿还融资，分子现金加C再减? 实际上追加现金到信用账户，如果不还款，则现金增加C，证券市值65，负债50，比例=(65+C)/50。若追加的现金直接偿还融资，则现金不增加（或增加再减少），负债减少C，证券市值65，比例=(65)/(50-C)。设=1.5 => 65 =75 -1.5 C =>1.5 C=10 => C=6.666...万。但题目分两问："如果追加现金，需要多少？如果卖出股票偿还融资，需要卖出多少市值？" 第一问"追加现金"通常指单纯增加担保物（现金作为保证金），不偿还融资。融资融券实务中，客户可以通过"现金还款"或"卖券还款"偿还负债；也可以提交担保物（现金/证券）提高维持担保比例而不减少负债。题目后面并列"卖出股票偿还融资"，说明前一问"追加现金"是不偿还融资、仅增加分子；后一问是卖券还款同时减少分子分母。这样对比才有意义：追加现金10万 vs 卖券还款20万市值。这个对比是经典结论：卖券还款需要的金额更大，因为分子分母同减。

但等等，需要再想想。经典问题：维持担保比例低于平仓线后，要恢复到警戒线以上，可追加担保物或偿还部分融资。公式：设当前资产A（市值），负债L，当前比例 r=A/L < 目标比例 R。

追加现金x（不偿债）：(A+x)/L = R => x = R L - A。这里 R L - A = 1.5*50 -65 =75-65=10。

卖券还款y：(A-y)/(L-y)=R => A - y = R L - R y => R y - y = R L - A => y(R-1)= R L - A => y = (R L - A)/(R-1) =10/0.5=20。是的。

也可以从公式看出 y = x/(R-1) =10/0.5 =20（因为 R L - A =10）。这成立当R>1。

所以答案：追加现金10万元；卖出股票20万元市值（用以偿还融资）。

需要给出清晰的计算过程。可能还要指出对应股价：跌到130%时，股价累计下跌35%。

再检查一下题目中"客户信用账户里有自有资金50万元，又融资50万元，全部买入同一只股票（合计市值100万元）。" 维持担保比例公式=（现金+信用账户证券市值）÷融资负债。注意，自有资金50万一开始是现金，然后全部买入股票，所以买入后现金=0，证券市值=100万。但有些理解：分子中"现金"可能包括客户自有资金？不，买入后已经变成股票了。信用账户里的资产=证券市值100万（没有现金剩余）。融资负债=50万。维持担保比例=200%。这与常规两融一致：投资者以50万保证金融资50万买入100万股票，维持担保比例=总资产/负债 =100/50=200%。注意有的券商维持担保比例分子含"现金及信用证券账户内证券市值总和"，分母含"融资买入金额+融券卖出证券数量×当前市价+利息及费用总和"。此处简单。

需要确认平仓线和警戒线定义：触及 = 等于。问题"下跌多少会触及"——当比例降到该线。因为比例是连续随股价下降，触及即等于。答案25%和35%。

可能需要讨论"下跌多少"是相对于买入价。初始100万市值。警戒线时总市值=融资负债×150% =75万，跌去25万，跌幅25%。平仓线时总市值=50×130%=65万，跌去35万，跌幅35%。注意不是从警戒到平仓再跌多少；可以补充：从触及警戒线再到平仓线，需市值从75万跌到65万，再跌10万，相当于在警戒线基础上再跌 10/75≈13.33%，但相对初始买入价累计35%。题目只问下跌多少触及各线，所以相对初始跌幅即可。

还要注意："全部买入同一只股票"意味着股票市值就是该股票，股价下跌幅度=市值下跌幅度（假设持股数不变）。

组织答案：

设融资负债 F=50万不变。买入后账户现金0，股票市值初始 M0=100万。维持担保比例 P=M/F（现金为0）。

(1) 警戒线：M=150%×50=75万，市值从100万跌到75万，跌幅25%。
平仓线：M=130%×50=65万，跌幅35%。

(2) 处于130%时：M=65万，F=50万，现金0。
方案A 追加现金 c（不偿还融资，仅作担保）：
(65+c)/50=150% → c=10万。
方案B 卖出市值 s 的股票并偿还融资（分子、分母同减 s）：
(65−s)/(50−s)=150% → 65−s =75−1.5s → 0.5s=10 → s=20万。
验算：卖后市值45万，负债30万，45/30=150%。

结论：追加现金10万；或卖出20万市值股票还款。附带说明：卖券还款额是追加现金的2倍，因为分子分母同时减少；若追加的现金直接用于归还融资，则只需约6.67万（65/(50−c)=1.5解得c≈6.67万）——要不要提？题目明确区分"追加现金"和"卖出股票偿还融资"。为避免混淆，可以加一个备注：本问中"追加现金"按"存入信用账户作为担保、不偿还融资负债"理解；若把追加的现金立即用于归还融资，则结果不同（约6.67万），但这与题中并列的"卖出股票偿还融资"不是同一情形。这个备注有价值吗？用户可能不希望复杂化，但专业上有歧义。题目表述"客户希望恢复到150%：如果追加现金，需要多少？如果卖出股票偿还融资，需要卖出多少市值？" 明确把追加现金和卖出股票偿还融资并列。在中国两融语境，"追加担保物"可以是现金，现金进入信用账户后就是保证金（分子），不自动偿还融资；要偿还融资需要"直接还款"或"卖券还款"。所以追加现金理解为增加分子不减少分母，正确。追加现金作为担保物，券商一般接受，维持担保比例分子含现金。答案10万。

但要不要补充"若追加现金后即刻用于偿还融资，则需6.67万元"作为辨析？可能不必要，甚至会让用户困惑。不过这是一个常见易错点，可以一句话备注。考虑用户是出题/做题风格，可能期待标准答案：追加现金10万，卖券20万。我会给标准答案并加简短说明，不引入6.67万以免干扰，或者放在备注里。让我权衡。

用户问了两个具体数字。如果我引入6.67万，可能让用户觉得答案不唯一。但题目"追加现金"在有些教材里其实理解为"追加保证金（可以是现金或证券）"，公式是 (资产+追加)/(负债) = 比例。例如经典公式：维持担保比例低于130%时，投资者需追加担保物，追加后不得低于150%。设追加x，则（现有资产+x）/负债 ≥150%。这是标准两融规则。所以追加现金=10万是标准。卖券还款=20万也是标准。无需6.67万备注，除非为严谨。我可以加一句："这里追加现金指作为担保物存入、不冲减融资负债；卖出股票则明确用于偿还融资。" 这足以消除歧义，不给6.67万数字。

最终用中文回答，结构清晰。使用万元单位。注意写公式。

还需要确认"股价下跌多少"：因为全部买入同一只股票，市值跌幅等于股价跌幅。初始买入价对应市值100万；股价跌25%，市值75万；跌35%，市值65万。可以表述为"较买入价下跌25%/35%"。

检查是否有利息费用：题目不考虑，融资负债恒为50万。好。

再考虑是否自由资金50万还留在信用账户作为"现金"？题目："客户信用账户里有自有资金50万元，又融资50万元，全部买入同一只股票（合计市值100万元）。" 既然全部买入，自有资金和融资都变成股票，现金=0。分子=现金0+证券市值100万。即使理解为自有资金50万还在账户（现金）+融资买入50万股票，合计市值？题目说"全部买入同一只股票（合计市值100万元）"，明确100万全是股票市值，所以现金为0。初始比例=100/50=200%。一致。

不过另一种可能：客户信用账户里有自有资金50万（作为保证金/现金），又融资50万，全部买入股票合计市值100万——这意味着用自有资金50+融资50=100买入股票，买入后账户里股票市值100万，没有剩余现金。是的。

最终答案写作：

记融资负债 L=50万元（不变），买入后账户无现金，股票市值初始 V0=100万元。股价跌幅为 d 时 V=100(1−d)。

维持担保比例 = V/L。

(1) 150%: V=1.5L=75万 → d=(100−75)/100=25%。
130%: V=1.3L=65万 → d=35%。

(2) 已触及130%：V=65万，L=50万。
①追加现金x作担保（不偿债）：(65+x)/50=1.5 ⇒ x=10万元。
②卖出市值y股票并偿还融资（资产、负债同减y）：(65−y)/(50−y)=1.5 ⇒ y=20万元。
验算：余股票45万、负债30万，45/30=150%。

附：从警戒线到平仓线，市值需再由75万降至65万（相对买入价累计由25%到35%）。可写可不写。我写一小句。

也可以强调结论：卖券还款所需金额大于追加现金，因为还款使分子分母等额减少，而比例>100%时这会"更费力"地提升比例。一句即可。
