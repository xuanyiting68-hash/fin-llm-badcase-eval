1. Are OLS coefficient estimates still unbiased?

This is a classic econometrics question. Let me think through the answer carefully.

**1. Are OLS coefficients still unbiased under heteroskedasticity?**

Yes. Unbiasedness of OLS relies on the Gauss-Markov assumptions:
- Linearity in parameters (MLR.1)
- Random sampling (MLR.2)
- No perfect collinearity (MLR.3)
- Zero conditional mean: E(u|X) = 0 (MLR.4)

Heteroskedasticity violates MLR.5 (homoskedasticity: Var(u|X) = σ²). Violating MLR.5 does NOT affect unbiasedness or consistency. So OLS coefficients remain unbiased and consistent under heteroskedasticity (as long as the zero conditional mean assumption holds).

However, OLS is no longer BLUE (Best Linear Unbiased Estimator) — it loses efficiency. The Gauss-Markov theorem requires homoskedasticity. Under heteroskedasticity, there exist more efficient estimators (like GLS/WLS).

**2. Can t-tests still be used?**

No, not directly. The usual OLS standard errors are computed under the homoskedasticity assumption. Under heteroskedasticity:
- The usual formula for Var(β̂) = σ²(X'X)⁻¹ is incorrect
- The correct variance is Var(β̂) = (X'X)⁻¹ X'ΩX (X'X)⁻¹ where Ω is the diagonal matrix of error variances
- So the usual standard errors are biased, which means t-statistics and F-statistics don't follow their usual distributions (not even asymptotically with the wrong SEs)
- t-tests, confidence intervals, p-values based on usual SEs are invalid
- This can lead to over- or under-rejection — typically with financial data, standard errors are underestimated in some contexts, leading to spurious significance, but it can go either way

Important nuance: The t-test using the conventional standard error is invalid. But you CAN still do t-tests if you use heteroskedasticity-robust (White) standard errors.

**3. How to handle it?**

There are several approaches:

**(a) Heteroskedasticity-robust standard errors (White standard errors / Eicker-Huber-White)**
- Most common approach in applied work
- Keep OLS estimates (still consistent), just fix inference
- White (1980) estimator: Var̂(β̂) = (X'X)⁻¹ [Σ x_i x_i' û_i²] (X'X)⁻¹
- Variants: HC0, HC1, HC2, HC3 (HC3 recommended for small samples, HC1 common default)
- In Stata: `reg y x, robust`
- In R: `sandwich` package with `vcovHC`, `coeftest` from `lmtest`
- In Python: `statsmodels` with `cov_type='HC1'` or `'HC3'`
- Advantage: valid inference asymptotically without needing to model the heteroskedasticity
- Disadvantage: OLS is still inefficient compared to GLS/WLS; robust SEs can be larger (or smaller); small-sample performance may vary

**(b) Since it's stock daily returns — consider clustering and autocorrelation too**
- Stock returns often have volatility clustering (ARCH/GARCH effects), which shows up as heteroskedasticity
- Also might have autocorrelation
- If the panel/time series structure matters: Newey-West HAC standard errors for time series (accounts for autocorrelation + heteroskedasticity)
- If multiple stocks (panel data): cluster-robust standard errors at the stock level
- The user said "股票日收益率" (stock daily returns) — could be one stock time series or a panel. If it's a single stock time series, Newey-West is appropriate. If panel (many stocks), clustered SEs.

**(c) Model the heteroskedasticity directly**
- WLS/GLS: if you can specify the form of heteroskedasticity (e.g., variance proportional to some variable), use WLS for efficiency
- Feasible GLS (FGLS): estimate the variance function
- For financial returns: GARCH-type models model the conditional variance explicitly — this is often the natural approach for daily stock returns. E.g., estimate a GARCH(1,1) on the returns, or include the mean equation with GARCH errors
- For a thesis on stock returns, mentioning GARCH or volatility modeling might be appreciated

**(d) Transform the data**
- Log transformation if appropriate (for returns, they're often already in log or simple return form, so this may not apply)
- Actually for returns this is less common

**Diagnostics check:**
- How did they detect heteroskedasticity? Breusch-Pagan test, White test, residual plots
- Also worth checking whether the heteroskedasticity signals model misspecification (e.g., missing variables, wrong functional form) — heteroskedasticity can be a symptom of misspecification. For stock returns, volatility clustering is expected, so it's often inherent.

**Practical recommendation for the thesis:**

For a typical undergraduate/master's thesis with OLS on stock returns:
1. Report OLS coefficients (still consistent/unbiased — state this)
2. Use heteroskedasticity-robust standard errors (White) — minimum standard practice
3. If time series of a single stock: Newey-West HAC SEs
4. If panel of multiple stocks: cluster-robust SEs at the firm level (possibly two-way clustering firm + time, given market-wide shocks)
5. Optionally: GARCH model as robustness, or WLS
6. Do robustness checks: compare results with and without robust SEs

Also should mention: report the test for heteroskedasticity (BP/White test) in the thesis, then justify the remedy.

**One more nuance on unbiasedness:** unbiasedness requires E(u|X)=0. If heteroskedasticity arises from misspecification (e.g., omitted variables correlated with X), then unbiasedness could fail too — but that's a different problem. Worth a brief note.

**Efficiency point:** Under heteroskedasticity, OLS is no longer BLUE; WLS/GLS is more efficient if the variance structure is known/correctly specified. But in practice with unknown form, OLS + robust SEs is standard.

**一、系数估计还是无偏的吗？——是**

无偏性（以及一致性）依赖于核心假定：
- 模型线性、随机抽样、无完全共线性
- 关键：零条件均值 E(u|X)=0（外生性）

异方差违反的是同方差假定 Var(u|X)=σ²，这不影响无偏性和一致性。所以：
- ✅ 系数仍然无偏、一致
- ❌ 但 OLS 不再是 BLUE（高斯-马尔可夫定理失效），即不再是最有效的线性无偏估计量

注意一点：如果异方差是模型误设（遗漏变量、函数形式错误）的"症状"，而外生性也被破坏，那无偏性才会出问题。建议先确认模型设定没问题。

**二、t 检验还能用吗？——默认的不行，换稳健标准误后可以**

经典标准误公式 σ²(X'X)⁻¹ 是在同方差假定下推导的。异方差下真实的方差是 (X'X)⁻¹X'ΩX(X'X)⁻¹。用错的标准误：
- t 统计量不再服从 t 分布（即使大样本也不服从正态）
- p 值、置信区间都不可信，可能过度拒绝（虚假的显著）或拒绝不足

但如果把标准误换成异方差稳健标准误，t 检验在大样本下是有效的。
