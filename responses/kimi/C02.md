## 问题

某公司近3年的营业收入增速分别为10%、12%、15%，应收账款增速分别为35%、48%、60%，净利润逐年增长，但经营活动现金流量净额连续3年为负。请指出其中的风险信号，并说明还应核查哪些指标。

## 回答

# 一、主要风险信号

## 1. 应收账款增速与收入增速严重背离

三年累计看：营业收入增长约 **41.7%**（1.10×1.12×1.15），而应收账款增长约 **219.7%**（1.35×1.48×1.60）。应收账款与收入的比值扩大了约1.3倍，且缺口逐年放大（25→36→45个百分点）。这可能意味着：

- **收入确认激进或虚增收入**：提前确认收入、虚构销售、向渠道压货
- **信用政策异常放松**：为冲销量而放宽客户信用条件，牺牲回款质量
- **客户质量恶化或丧失议价权**：下游客户付款能力下降，被迫接受更长账期

## 2. 净利润与经营现金流持续背离

利润是权责发生制下的"账面数字"，现金流才是"真金白银"。**连续三年净利润增长但经营现金流为负**，说明利润没有现金支撑，属于典型的"纸面利润"，是财务造假案例中最高频的预警信号组合之一（虚增收入→沉淀为应收账款→利润增加但现金流入为零）。

## 3. 叠加风险：流动性与坏账隐患

- 营运资金被应收账款大量占用，经营"失血"，公司只能靠**筹资输血**维持运转
- 应收账款快速膨胀，**坏账风险在账面积累**，未来可能集中爆发大额减值
- 若回款持续恶化，可能引发债务违约链条

# 二、应进一步核查的指标

| 类别 | 核查指标 |
|---|---|
| **盈利质量** | 净现比（经营现金流净额÷净利润）、收现比（销售收现÷营业收入，正常应≥1）、扣非净利润占比 |
| **应收账款质量** | 应收账款周转率/周转天数（与同行对比）、应收账款占营收比重、**账龄结构**、坏账准备计提比例（是否低于同行、是否变更计提政策）、期后回款情况 |
| **收入真实性** | 前五大客户集中度及变化、关联方交易占比、第四季度收入占比（有无期末突击确认）、毛利率是否异常高于同行、销售退回情况 |
| **存货联动** | 存货增速与跌价准备（收入造假常伴随存货异常） |
| **偿债与流动性** | 流动比率、速动比率、资产负债率、利息保障倍数、货币资金中有息负债覆盖率 |
| **现金流结构** | 投资、筹资现金流情况——是否靠持续举债或股权融资维持经营；自由现金流 |
| **外部印证** | 审计意见类型、应收账款保理/证券化（是否通过出表美化）、合同负债变化、主要欠款方的工商信息与关联关系核查 |

**核查要点**：若发现应收账款周转天数持续拉长、坏账计提比例低于同行、收现比明显小于1、或存在大额关联交易，则基本可以确认收入质量存在重大问题，需警惕财务造假和业绩"爆雷"风险。
