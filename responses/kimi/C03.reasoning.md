# C03 · Kimi · 思考过程

用户问的是一道财务计算题，需要计算并解释。

题干：某制造业公司总市值60亿元，上一年度归母净利润6亿元。其中，持有股票投资产生的公允价值变动收益对归母净利润的税后影响为3.5亿元。有人说“市盈率只有10倍，非常便宜”。要求分别计算按归母净利润的市盈率，以及剔除该项收益后的调整后市盈率，并说明哪个更适合评估这家公司。

计算：
1. 按归母净利润的市盈率 = 总市值 / 归母净利润 = 60 / 6 = 10倍。
2. 剔除该项收益后的调整后归母净利润 = 6 - 3.5 = 2.5亿元。
   调整后市盈率 = 60 / 2.5 = 24倍。

需要说明哪个更适合评估公司：
- 该公司是制造业公司，主业应该是制造业经营。持有股票投资产生的公允价值变动收益属于非经常性损益/非核心经营收益（更准确说，公允价值变动收益通常计入当期损益，但不属于经营活动产生的利润，且波动大、不可持续；若该股票投资被归类为交易性金融资产或其他非流动金融资产，其公允价值变动计入当期损益）。对于制造业公司估值，应使用可持续、可重复的核心经营利润。
- 3.5亿元占归母净利润6亿元的58.3%，占比很高，剔除后核心净利润只有2.5亿元。因此用10倍市盈率判断“非常便宜”会严重高估盈利质量、低估估值。调整后24倍才更接近主业估值水平。
- 更适合的是剔除后的调整后市盈率（或扣非市盈率），因为它剔除了偶发性、波动性、非经营性的公允价值变动收益，反映主营制造业的可持续盈利能力。对于制造业企业，应使用扣非归母净利润/经营性利润对应的市盈率；同时还要结合现金流、资产负债表中金融资产规模、该收益是否已变现、行业可比公司估值、成长性与周期性等。
- 需要注意：如果该股票投资是公司长期战略性投资、且投资业务本身就是公司常设业务（如公司实际为控股/投资平台），则可能不应完全剔除。但题干明确是制造业公司，且收益来自“持有股票投资产生的公允价值变动”，更像非主业、波动收益，应剔除或至少单独披露。可以补充：若该金融资产规模较大且长期存在，市场有时会采用分部估值（制造业经营利润按制造业PE + 金融资产按净资产/市值计价），而非简单把公允价值变动损益资本化。

需要严谨一点：题目说“对归母净利润的税后影响为3.5亿元”，说明已经考虑了税和少数股东影响，直接扣减即可。调整后市盈率 = 60/(6-3.5)=24倍。

还要指出“市盈率只有10倍非常便宜”的问题：市盈率的分母含一次性/波动性收益，导致PE被压低。制造业公司的估值应看经营性利润。若公允价值变动收益未实现，现金流并未同步增加，进一步削弱其作为估值基础的可靠性。

需要注意是否要考虑“归母净利润”和“总市值”对应关系：总市值对应全体股东权益市值，而归母净利润对应母公司股东应占利润。通常在A股语境，用总市值/归母净利润计算PE是常见做法（虽有更严谨用“归母市值”但无法获得）。题目指定按归母净利润，接受。

可能还要计算占比：3.5/6=58.33%；调整后净利润为2.5亿元；调整后PE是原来的2.4倍（因为分母从6变为2.5，PE变为24，即10*6/2.5=24）。

最终答案要清晰分步。语言用中文。可以写成：
- 静态/报告口径PE = 60/6=10x。
- 调整后扣非核心净利润 = 6-3.5=2.5亿元。
- 调整后PE = 60/2.5=24x。

哪个更适合：调整后（扣非/核心）市盈率更适合。理由：
1) 制造业公司价值主要来自主营制造业务的持续盈利能力，股票公允价值变动损益属投资性/金融性、非经常或高波动项目，不代表制造业务竞争力；
2) 该项税后影响占归母净利58.3%，权重过大，使报告PE被严重扭曲；
3) 公允价值变动常未实现、无对应经营现金流，未来可能反转，以其资本化会低估风险；
4) 估值应与可比公司口径一致，采用扣非归母净利润/经营利润。

补充：更稳妥做法：用扣非后净利润并结合多年平均、现金流验证；若投资资产重大，可分部估值：制造主业按调整后利润×可比PE，金融资产按可变现净值/市值单独计价，再加总检验60亿市值是否合理。不要直接把“公允价值变动收益”当作可持续利润给制造业PE。

还要回答“非常便宜”的判断：按报告PE 10倍看似便宜，但剔除后24倍并不便宜（相对一般制造业而言需结合成长性；至少不能据此断言非常便宜）。

需要注意是否有隐含陷阱：公允价值变动收益对归母净利润税后影响3.5亿。有人据此说“市盈率只有10倍”。这里“据此”可能指按归母净利润。要求我们分别计算并说明哪个更适合。答案较直接。

最后给出结论：调整后市盈率更适合；报告口径的10倍不宜用于判断制造业公司便宜与否。若必须用单一指标，应用扣非归母净利润对应的PE，即24倍，并再与行业可比、成长性、周期位置比较。

可以加入公式：
PE_report = M / NP = 60/6=10
NP_adj = NP - FV_after_tax = 6 - 3.5 = 2.5
PE_adj = 60/2.5=24
 distortion: 报告利润中58.3%来自该项；调整后利润仅为报告利润的41.7%。

我们也应考虑：是否该收益“对归母净利润的税后影响”意味着已经在归母净利润中。是的。若题目说“对归母净利润的税后影响”即为归属于母公司的税后净影响，不需要再乘（1-25%）或少数股东比例。特别说明避免重复扣税。

最终用较简洁但完整的表达。用户可能是考试/分析题，期望数字和解释。可以提到“如果该公司是投资控股型则另当别论，但题设是制造业公司”。

最终输出中不要用太多花哨格式，但可用列表。

检查是否有其他细节：总市值60亿元，上一年度归母净利润6亿元。市盈率 = 市值 / 净利润。调整后收益剔除。正确。
