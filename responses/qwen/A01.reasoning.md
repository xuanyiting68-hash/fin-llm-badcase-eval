Let me solve this step by step using the put-call parity for European options on a non-dividend paying stock.

Given information:
- Current stock price: S = 50
- Strike price: K = 52
- Time to maturity: T = 6 months = 0.5 years
- European call option price: C = 5
- Risk-free rate: r = 4% per annum (continuously compounded)
- No dividends

The put-call parity for European options on a non-dividend paying stock is:

C + K * e^(-rT) = P + S

Where:
- C = call option price
- P = put option price
- S = current stock price
- K = strike price
- r = risk-free rate
- T = time to maturity

We need to find P:

P = C + K * e^(-rT) - S

Let me calculate:

K * e^(-rT) = 52 * e^(-0.04 * 0.5)
= 52 * e^(-0.02)
= 52 * 0.98019867...
= 50.9703...

P = 5 + 50.9703 - 50
= 5.9703...

So P ≈ 5.97 元
