Let me carefully calculate the Black-Scholes model for a European call option step by step.

Given parameters:
- S (current stock price) = 100
- K (strike price) = 100
- T (time to maturity) = 1 year
- r (risk-free rate, continuous compounding) = 3% = 0.03
- σ (annualized volatility) = 20% = 0.20
- q (dividend yield) = 0

Black-Scholes formula for a European call option:
C = S * N(d1) - K * e^(-rT) * N(d2)

Where:
d1 = [ln(S/K) + (r + σ²/2) * T] / (σ * √T)
d2 = d1 - σ * √T

Let me calculate step by step:

Step 1: Calculate ln(S/K)
S/K = 100/100 = 1
ln(1) = 0

Step 2: Calculate σ²/2
σ² = 0.20² = 0.04
σ²/2 = 0.02

Step 3: Calculate r + σ²/2
0.03 + 0.02 = 0.05

Step 4: Calculate (r + σ²/2) * T
0.05 * 1 = 0.05

Step 5: Calculate numerator of d1
ln(S/K) + (r + σ²/2) * T = 0 + 0.05 = 0.05

Step 6: Calculate denominator of d1
σ * √T = 0.20 * √1 = 0.20 * 1 = 0.20

Step 7: Calculate d1
d1 = 0.05 / 0.20 = 0.25

Step 8: Calculate d2
d2 = d1 - σ * √T = 0.25 - 0.20 = 0.05

Step 9: Find N(d1) and N(d2)
