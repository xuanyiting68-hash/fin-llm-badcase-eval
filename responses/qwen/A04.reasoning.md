Let me carefully work through this problem step by step.

Given information:
- Monthly return arithmetic mean: 1.0%
- Monthly return standard deviation: 4.5%
- Monthly risk-free rate: 0.2%

The question asks me to:
1. Calculate the monthly Sharpe ratio using the arithmetic mean of monthly excess returns
2. Annualize it using the √12 rule
3. Show the calculation process

Step 1: Calculate monthly excess return arithmetic mean
Monthly excess return = Monthly return - Monthly risk-free rate
Monthly excess return arithmetic mean = 1.0% - 0.2% = 0.8%

Step 2: Calculate monthly Sharpe ratio
Sharpe ratio (monthly) = Monthly excess return arithmetic mean / Monthly return standard deviation
Sharpe ratio (monthly) = 0.8% / 4.5% = 0.8 / 4.5 = 8/45 ≈ 0.1778

Step 3: Annualize using the √12 rule
The √12 rule for annualizing the Sharpe ratio:
Annualized Sharpe ratio = Monthly Sharpe ratio × √12

Annualized Sharpe ratio = (8/45) × √12
√12 = 2√3 ≈ 3.4641

Annualized Sharpe ratio = (8/45) × 3.4641 ≈ 0.1778 × 3.4641 ≈ 0.6158
