Let me work through this problem step by step.

**Given information:**
- Account capital: 100,000 yuan
- Maximum planned loss per trade: 1% of account = 1,000 yuan
- Planned buy price: 50 yuan
- Stop loss price: 47 yuan (conditional order)
- Slippage: 0.05 yuan for both buy and sell
- No commissions or taxes
- Must buy in multiples of 100 shares (Shanghai/Shenzhen main board)

**Part (1): Maximum number of shares to buy**

First, let me calculate the planned loss per share:
- Actual buy price = 50 + 0.05 = 50.05 yuan (slippage on buy means we pay more)
- Actual stop loss sell price = 47 - 0.05 = 46.95 yuan (slippage on sell means we receive less)
- Planned loss per share = 50.05 - 46.95 = 3.10 yuan

Maximum planned loss = 1% × 100,000 = 1,000 yuan

Maximum shares based on loss limit:
- Shares = 1,000 / 3.10 = 322.58 shares

Since we must buy in multiples of 100 shares:
- Maximum shares = 300 shares

Let me verify the capital requirement:
- Cost = 300 × 50.05 = 15,015 yuan
- This is within the 100,000 yuan account, so it's fine.

Wait, let me reconsider. The problem says "按正常止损成交假设计算" - meaning we calculate based on the normal stop loss execution assumption.

The planned loss per share with slippage:
- Buy at: 50 + 0.05 = 50.05
- Sell at stop loss: 47 - 0.05 = 46.95
- Loss per share = 50.05 - 46.95 = 3.10 yuan

Maximum shares = 1,000 / 3.10 = 322.58

Rounded down to nearest 100: 300 shares.

Check: 300 × 3.10 = 930 yuan ≤ 1,000 yuan ✓

So maximum is 300 shares.

**Part (2): Gap down to 45 yuan, actual loss percentage**

If the stock gaps down to 45 yuan the next day, the conditional order executes at 45 yuan (no additional slippage as stated).

- Buy price: 50.05 yuan (50 + 0.05 slippage)
- Actual sell price: 45 yuan (no additional slippage)
- Loss per share = 50.05 - 45 = 5.05 yuan
- Number of shares: 300
- Total loss = 300 × 5.05 = 1,515 yuan

Loss percentage of account:
- 1,515 / 100,000 = 1.515%

So the actual loss is 1.515% of the account.
