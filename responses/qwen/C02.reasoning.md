# C02 · 千问 · 思考过程

用户提供了一家公司的部分财务数据，要求指出其中的风险信号，并说明还应核查哪些指标。

已知数据：
1. 营业收入增速：10%、12%、15%（逐年增长，且增速在加快）。
2. 应收账款增速：35%、48%、60%（逐年大幅增长，且增速远高于营业收入增速）。
3. 净利润：逐年增长。
4. 经营活动现金流量净额：连续3年为负。

任务：
1. 指出风险信号。
2. 说明还应核查哪些指标。

思考过程：

一、 分析风险信号
1. **应收账款增速远超营业收入增速**：
   - 营收增速最高15%，而应收账款增速高达35%-60%。这说明公司的销售并没有带来相应的现金回款，可能是放宽了信用政策以刺激销售（甚至可能是虚假销售/提前确认收入）。
   - 风险：坏账风险增加，资金链断裂风险，收入质量低下，甚至存在财务造假（虚增收入）的嫌疑。
2. **净利润增长与经营现金流背离（盈利不收现）**：
   - 净利润逐年增长，但经营活动现金流连续3年为负。这说明公司的利润只是“纸上富贵”，没有实际的现金流入支撑。
   - 风险：利润质量极差，可能存在通过应收账款、存货等科目操纵利润的行为；公司面临严重的流动性危机，日常经营需要不断外部输血。
3. **整体商业模式与营运能力恶化**：
   - 收入、利润在增长，但现金流为负，说明公司在产业链中的话语权可能较弱（对下游客户赊销，对上游供应商可能需要现结或账期短），或者行业景气度下行，公司靠牺牲现金流来换取账面规模。

二、 确定还应核查的指标
为了进一步验证上述风险，需要从多个维度进行深入核查：

1. **收入与应收账款质量相关指标**：
   - **应收账款周转率/周转天数**：看回款速度是否逐年恶化。
   - **应收账款账龄分析及坏账准备计提比例**：看长账龄应收账款占比是否增加，坏账计提是否充分（有无通过少计提坏账来虚增利润）。
   - **前五大客户集中度及关联关系**：看是否依赖少数客户，是否存在关联方交易输送利益或虚构交易。
   - **销售商品、提供劳务收到的现金 / 营业收入**（收现比）：直接衡量收入含金量，正常应接近或大于1（考虑增值税）。

2. **利润质量与现金流相关指标**：
   - **净现比（经营活动现金流量净额 / 净利润）**：正常应大于1，连续为负说明利润毫无现金支撑。
   - **扣非净利润及非经常性损益明细**：看净利润增长是否靠变卖资产、政府补助、投资收益等非主营业务支撑。
   - **各项资产减值损失（特别是信用减值损失和资产减值损失）**：看是否通过不计提减值来粉饰利润。

3. **存货与供应链相关指标（因为经营现金流为负，除了应收，存货和应付也是关键）**：
   - **存货增速及存货周转率**：如果存货增速也远超营收增速，可能存在产品滞销、积压，甚至虚增存货（存货也是吸收现金流的黑洞）。
   - **应付账款及票据增速**：看公司是否拖欠供应商货款。如果应付账款增速低或下降，说明公司对上游缺乏议价能力，进一步解释现金流为负的原因。
   - **购买商品、接受劳务支付的现金 / 营业成本**（付现比）。

4. **偿债能力与流动性风险指标**：
   - **资产负债率、流动比率、速动比率**：评估短期和长期偿债压力。
   - **货币资金余额及受限资金比例**：看账面是否有钱，是否存在“存贷双高”（账面有钱却大量借款，可能是资金被大股东占用或财务造假）。
   - **利息保障倍数**：看利润是否足以支付利息。
   - **短期借款、一年内到期的非流动负债增速**：看公司是否在靠不断借新还旧维持生存（筹资活动现金流是否大幅为正）。

5. **其他非财务/表外指标**：
   - **审计意见类型**：看注册会计师是否出具了非标意见（保留、否定、无法表示意见），或强调事项段。
   - **关联交易占比**：是否存在通过关联方虚构业务。
   - **行业整体情况与同行业可比公司对比**：看该公司的异常表现是行业共性还是个体特例（如果同行现金流都很好，它很差，造假或经营恶化的概率极大）。
   - **董监高及大股东股权质押/减持情况**：大股东是否高位套现，质押率是否过高（爆仓风险）。

三、 结构化输出
将思考内容整理成清晰、结构化的文字。
分为两大部分：
第一部分：风险信号分析（归纳为3-4个核心风险点，结合题目给出的数据）。
第二部分：还应核查的指标（分类列出，并说明核查目的）。

审查逻辑：
- 营收增速10-15%，应收增速35-60% -> 剪刀差扩大 -> 放宽信用/虚增收入/坏账风险。
- 净利增长，经营现金流连续为负 -> 盈利质量差/纸上富贵/流动性枯竭。
- 核查指标要全面：应收、存货、现金流、利润结构、偿债、表外及审计等。

语言风格：专业、客观、条理清晰，使用标准的财务分析术语。

微调：
在风险信号部分，点出“财务造假（虚增收入/利润）”的嫌疑，因为这种典型的“高应收、高利润、负现金流”是经典的财务造假特征（如康得新、康美药业等早期特征）。
在核查指标部分，强调“收现比”、“净现比”、“存贷双高”等实务中非常关键的排雷指标。

最终输出结构：
一、 风险信号分析
  1. 收入质量低下与坏账风险（应收 vs 营收）
  2. 利润质量极差与“纸上富贵”（净利 vs 现金流）
  3. 流动性危机与资金链断裂风险（连续负现金流）
  4. 潜在的财务造假嫌疑（综合特征）
二、 还应核查的核心指标及目的
  1. 盈利与现金流质量指标（收现比、净现比等）
  2. 资产质量与营运能力指标（应收账款账龄、存货、应付等）
  3. 利润结构与真实性指标（扣非净利、减值准备等）
  4. 偿债能力与资金链指标（货币资金、有息负债、存贷双高等）
  5. 外部与非财务指标（审计意见、关联方、同行业对比等）

检查有无遗漏：题目要求“指出其中的风险信号，并说明还应核查哪些指标”。结构完全符合要求。内容详实且专业。可以生成最终回答。
