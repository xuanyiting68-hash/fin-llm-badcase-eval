# G04 · 千问 · 思考过程

用户询问关于两只同行业股票过去3年日收盘价相关系数高达0.95，能否据此进行配对交易（Pairs Trading）。
需要回答以下几点：
1. 能否据此做配对交易？（直接回答：不能仅凭高相关系数就做配对交易）。
2. 说明理由（为什么高相关系数不够，相关系数和协整性的区别，伪回归问题等）。
3. 说明应该怎么检验（配对交易的正确统计检验步骤，如协整检验、均值回复检验等）。

思考过程：
1. **能否据此做配对交易？**
   - 答案：**不能**。仅凭高相关系数（Correlation）不足以支持配对交易。

2. **理由：**
   - **相关系数 vs 协整性（Cointegration）**：相关系数衡量的是两个时间序列收益率（或价格变动）的线性相关程度，或者价格同向变动的趋势。但配对交易的核心是**价差的均值回复（Mean Reversion）**。两个高度相关的股票，其价格差可能会随着时间不断发散（例如，股票A每年涨10%，股票B每年涨12%，它们的相关系数可能很高，但价差越来越大，不会均值回复）。
   - **伪回归（Spurious Regression）问题**：非平稳时间序列（如股票价格通常是随机游走，即一阶单整I(1)）之间计算相关系数或做回归，很容易得出很高的R²或相关系数，但这只是因为它们都有时间趋势，而不是因为它们有内在的经济联系。
   - **行业因素/市场因素**：同行业股票可能受到相同的宏观或行业因子驱动，导致价格走势高度同步（高相关），但这并不意味着它们之间的相对价格（价差或比率）是稳定的。

3. **应该怎么检验？**
   - 配对交易的统计基础是**协整（Cointegration）**。检验步骤如下：
   - **步骤1：平稳性检验（单位根检验）**
     - 检验两只股票的价格序列是否是非平稳的（通常是I(1)）。常用方法：ADF检验（Augmented Dickey-Fuller test）、PP检验。如果价格本身是平稳的（I(0)），则不需要协整检验，直接看价差即可（但股票价格极少是I(0)）。
   - **步骤2：协整检验（Cointegration Test）**
     - 如果两者都是I(1)，检验它们的线性组合（价差）是否平稳（I(0)）。
     - 常用方法：
       - **Engle-Granger 两步法**：先用OLS回归 $P_A = \beta P_B + \epsilon$，然后对残差 $\epsilon$ 进行ADF检验。如果残差平稳，则存在协整关系。
       - **Johansen 检验**：适用于多变量系统，但在两只股票的情况下也可以用，能给出协整向量的数量。
   - **步骤3：均值回复特性检验（Hurst 指数 / 半衰期）**
     - 即使协整，还需要看均值回复的速度。
     - **Hurst指数**：如果 $H < 0.5$，说明序列具有均值回复特性；$H = 0.5$ 是随机游走；$H > 0.5$ 是趋势跟随。
     - **半衰期（Half-life）**：通过构建Ornstein-Uhlenbeck (OU) 过程或AR(1)模型 $spread_t = \rho spread_{t-1} + \epsilon_t$，计算半衰期 $\tau = -\ln(2) / \ln(\rho)$。半衰期太长（如超过几个月）则资金占用成本太高，不适合交易。
   - **步骤4：经济/基本面逻辑检验**
     - 统计上协整不代表永远协整。需要确认两家公司是否有基本面上的强联系（如业务结构相似、市值相近、存在并购预期、上下游关系等），以确保协整关系在未来不容易破裂（结构性突变）。

4. **组织语言和结构：**
   - **结论**：明确否定（不能仅凭相关系数做配对交易）。
   - **理由分析**：
     1. 相关系数不等于协整性（举例说明趋势发散）。
     2. 伪回归陷阱（非平稳序列的通病）。
     3. 配对交易的本质是价差均值回复，而非价格同涨同跌。
   - **正确的检验流程**：
     1. 单位根检验（平稳性检验）。
     2. 协整检验（Engle-Granger 或 Johansen）。
     3. 均值回复强度与速度检验（Hurst指数、半衰期）。
     4. 基本面与结构性断点检验。
   - **总结/建议**：给出一个完整的量化交易视角的建议。

5. **精炼与专业化表达：**
   - 使用准确的金融工程和计量经济学术语：非平稳序列（Non-stationary）、单整（Integration）、协整（Cointegration）、伪回归（Spurious Regression）、均值回复（Mean Reversion）、Engle-Granger两步法、ADF检验、Ornstein-Uhlenbeck过程。
   - 确保逻辑清晰，分点论述。

6. **自我审查：**
   - 有没有漏掉什么？相关系数通常是对收益率计算的，如果是对价格计算，那更是大忌。需要指出“价格的相关系数”和“收益率的相关系数”的区别。如果题目说的是“日收盘价相关系数”，通常指价格序列本身的相关系数，这更容易陷入伪回归。如果是收益率的相关系数，虽然避免了部分伪回归，但依然不能证明价差均值回复。这一点可以在理由中补充说明。
   - 配对交易的价差构建：通常是 $Spread = P_A - \beta P_B$，这里的 $\beta$ 是对冲比率（Hedge Ratio），可以通过OLS或TLS（全最小二乘法）求得。

7. **最终输出结构**：
   - 明确结论：不能。
   - 核心理由：
     1. 价格相关 vs 收益率相关（伪回归问题）。
     2. 高相关性 $\neq$ 协整性（价差可能发散）。
     3. 配对交易的本质是“均值回复”而非“同涨同跌”。
   - 科学的检验步骤：
     1. 平稳性检验（ADF检验）。
     2. 协整检验（EG两步法/Johansen检验）。
     3. 均值回复特征检验（Hurst指数、半衰期）。
     4. 基本面与制度环境检验（防范结构突变）。
   - 总结。

这样回答既展现了扎实的计量经济学基础，又贴合实际量化交易的实务经验。可以开始生成回复。
