# C03 · DeepSeek · 思考过程

我们需要回答中文问题。需要计算市盈率并说明哪个更适合评估。公司总市值60亿元，上一年归母净利润6亿元。其中持有股票投资产生的公允价值变动收益对归母净利润的税后影响为3.5亿元。有人据此说市盈率只有10倍，非常便宜。请分别计算按归母净利润的市盈率，以及剔除该项收益后的调整后市盈率，并说明哪个更适合评估这家公司。

需要计算：市值60亿 / 归母净利润6亿 = 10倍。调整后归母净利润 = 6 - 3.5 = 2.5亿元（因为税后影响，直接从归母净利润剔除）。调整后市盈率 = 60 / 2.5 = 24倍。说明哪个更适合：剔除后更能反映主营业务/经常性盈利能力，因为公允价值变动收益具有波动性、非经常性/不可持续，评估制造业公司应看核心经营利润，调整后24倍并不便宜；但也要注意如果股票投资是长期策略或经常性，可能不能完全忽略，但对制造业估值核心应剔除。需要解释。

注意单位。回答要简洁。最终应中文。
