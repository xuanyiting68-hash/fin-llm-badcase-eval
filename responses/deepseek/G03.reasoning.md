我们需要回答中文金融风险管理问题。需要计算 VaR。组合市值1000万元，日收益率标准差1.5%，日收益率服从均值为0正态分布。求(1)99%置信水平下1日VaR；(2)用平方根法则估算10日VaR；(3)算法局限。

需要注意 VaR 通常绝对值损失。日收益率均值0，标准差1.5%。99%置信水平下正态分布分位数 z_0.99 = 2.326? 对于 VaR 置信水平99%，若收益率 r ~ N(0, sigma^2)，VaR = - (mu + sigma * z_alpha) 但 mu=0，损失为 -r 的分位数。置信水平99%的 VaR 是损失分布的99分位，即收益率分布的1%分位数。z_0.01 = -2.326，所以损失 = 0 - sigma*z_0.01? 设 VaR = - (mu + sigma * Phi^{-1}(1-c))? 当 c=99%，Phi^{-1}(0.01)=-2.326，VaR = - sigma * (-2.326)=2.326 sigma。金额 = 1000万 * 2.326 * 1.5% = 1000万 * 0.03489 = 34.89万。有的用单尾99% z=2.33。对。

10日 VaR 平方根法则：VaR_10 = sqrt(10) * VaR_1 = 34.89 * 3.1623 = 110.33万。也可以直接 1.5%*sqrt(10)*2.326*1000万 = 110.33万。注意如果 VaR 用百分比：1日 VaR率 = 2.326*1.5%=3.489%；10日=3.489%*sqrt10=11.033%；金额110.33万元。

第三问局限：平方根法则假设日收益率独立且同分布（i.i.d.），特别是无自相关、波动率恒定、正态分布；实际金融收益率存在波动率聚集、厚尾、自相关/均值回复、跳跃、 regime switching 等，导致平方根法则可能低估或高估风险；99%正态假设可能低估尾部风险；没有考虑流动性、持仓变化、期限结构等。需要展开。

第三部分：局限。可以分点：
1. 平方根法则基于独立同分布正态假设，实际日收益率有波动率聚集（GARCH效应）、厚尾，导致10日风险可能不是简单 sqrt(10) 倍。
2. 忽略自相关：若收益率有正/负自相关，实际多期方差会偏离 sqrt(T) 规则；均值回复会高估，趋势/持续会低估。
3. 正态分布假设低估极端损失概率，99% VaR 对尾部风险不敏感。
4. VaR 不满足次可加性（非一致性风险度量），无法描述尾部损失大小（应辅以 ES/CVaR、压力测试）。
5. 实际持仓可能在10日内变化、有流动性风险、非线性衍生品等，参数法/平方根法则不适用。

需要决定是否提到“平方根法则”的公式推导：如果日收益率独立同分布，10日方差=10*日方差，标准差=sqrt(10)*日标准差。这就是局限所在。
