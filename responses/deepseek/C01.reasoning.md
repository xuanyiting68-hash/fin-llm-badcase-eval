# C01 · DeepSeek · 思考过程

我们需要回答中文问题。需要判断公司业绩是否大幅改善并说明理由。用户给出A股公司年报：归母净利润2.7亿元，同比增长80%；扣非归母净利润1.2亿元，同比下降15%。当年出售子公司获得投资收益1.6亿元。问业绩是否大幅改善。需要分析。可能是财务分析题。归母净利润大增主要由于非经常性损益（出售子公司投资收益1.6亿元）。扣非后归母净利润下降15%，说明主营业务盈利下滑。因此业绩并未大幅改善，质量较差，利润增长不可持续。需要说明理由，可能提到非经常性损益贡献。注意数据勾稽：归母净利润2.7亿，扣非1.2亿，差额1.5亿，而出售子公司投资收益1.6亿，非经常损益可能还有其他。投资收益出售子公司通常计入非经常性损益。扣非净利润下降15%，说明剔除一次性收益后盈利下滑。结论：表面增长但实际经营业绩未改善，甚至恶化。需解释“扣非”指标。可提到净利润增长主要靠卖资产，不具备可持续性。回答简洁。可能还要判断“大幅改善”不成立。注意“归母净利润同比增长80%”看起来好，但扣非下滑。需要强调扣非更能反映持续经营能力。可以分点。

需要小心用户问“请判断这家公司的业绩是否大幅改善，并说明理由。”我们要直接回答。无需计算太多。可以给出数据：归母净利润2.7亿，扣非1.2亿；非经常性损益约1.5亿（2.7-1.2），其中出售子公司投资收益1.6亿。若没有这笔收益，利润可能下降或很低。但注意扣非净利润已经剔除出售收益后为1.2亿，同比下降15%，说明经常性业务盈利下滑。非经常性收益使总利润增长。业绩改善不可持续，质量不佳。也许“业绩是否大幅改善”应从两个层面：账面利润大幅增长但实际经营业绩未改善。答案：否，不认为业绩大幅改善。理由：归母净利润增长主要来自非经常性损益（出售子公司股权收益1.6亿），扣非归母净利润同比下降15%，反映主营业务盈利能力下滑；这种增长属于一次性收益，不具有持续性，甚至可能掩盖经营问题。需说明出售子公司导致未来可能还少了利润来源。可以加入“若剔除该投资收益，利润增长不可持续”。但要小心如果扣非已经剔除了这1.6亿，但扣非利润1.2亿仍下降15%，说明主营不是增长。归母净利润2.7 = 扣非1.2 + 非经常1.5。出售子公司收益1.6大于非经常1.5，可能有其他非经常损失0.1。非经常贡献约1.5亿。增长80%是基于去年归母净利润1.5亿（2.7/1.8=1.5），若扣除出售收益，去年扣非净利润约1.41亿（1.2/0.85≈1.41），所以主营利润下降。可以算一下，但不必。但给出增长80%即上年归母净利润为1.5亿元；扣非1.2亿同比下降15%，上年扣非约1.41亿元。这有助于说明。当年归母2.7亿主要由于1.6亿投资收益，扣除后经营利润下降。

可能需要注意：扣非归母净利润1.2亿元，同比下降15%；上年扣非=1.2/(1-0.15)=1.4118亿。归母净利润去年=2.7/1.8=1.5亿。如果去年归母1.5亿，扣非1.41亿，非经常仅0.09亿。今年非经常=1.5亿。所以归母增长完全靠非经常。这些数据可说明。可写：上年归母净利润约1.5亿元，扣非净利润约1.41亿元；本年扣非净利润1.2亿元，说明经常性盈利减少约0.21亿元；但非经常性损益约1.5亿元（主要是出售子公司收益1.6亿元）使归母净利润增至2.7亿元。因此增长质量差。

需要回答中文，简洁有力。可以结构化：结论、理由。注意要说明是否大幅改善：不能认定为经营业绩大幅改善。最终应提供专业判断。可能使用“账面利润改善，但实际经营业绩未改善甚至下滑”。可以提到“扣除非经常性损益后的归母净利润”是更反映主营的指标。

需要包含：出售子公司投资收益属于非经常性损益，不能持续。归母净利润增长80%主要由其贡献。扣非净利润下降15%说明主业盈利下滑。因此业绩改善缺乏可持续性，不能视为大幅改善。可能还要提醒：出售子公司可能降低未来合并范围盈利，若该子公司原本盈利，则未来业绩可能承压。但题目没说子公司盈亏，不必过度推断，但可以提“一次性收益”。

注意用户可能期望从“扣非净利润”和“投资收益”来判断。我们应准确。

需要以中文输出，不要多余。可以加小标题。最终回答在200-400字左右。

让我们构建回答：

结论：这家公司业绩并未真正大幅改善，只是账面利润因一次性收益大幅增长。

理由：
1. 归母净利润2.7亿元，同比增长80%，但当年出售子公司获得投资收益1.6亿元，属于非经常性损益，不具有可持续性。
2. 扣除非经常性损益后归母净利润仅1.2亿元，同比下降15%，说明公司主营业务/经常性业务盈利不仅没有改善，反而下滑。
3. 简单测算，上年归母净利润约1.5亿元（2.7/1.8），扣非净利润约1.41亿元（1.2/0.85）；本年归母净利润增加约1.2亿元，主要来自出售子公司等非经常性收益，而非主业增长。

因此，该公司业绩增长质量较差，不应视为大幅改善；需关注主业盈利能力下滑的风险。

这样很好。需要注意“扣非净利润约1.41亿元（1.2/0.85）”其实如果同比下降15%，上年扣非 = 1.2 / 0.85 ≈1.41。正确。

还要注意“归母净利润增加约1.2亿元”计算：去年归母=2.7/1.8=1.5，增加=1.2亿元；非经常增加约1.41? 计算今年非经常=2.7-1.2=1.5亿元，去年非经常=1.5-1.4118≈0.088亿元，增加约1.41亿元。出售子公司投资收益1.6亿元，比非经常总额还多，可能有其他非经常损失。所以增长主要来自非经常。可以不用精确。

如果计算：“本年非经常性损益约1.5亿元，而扣非净利润同比下降15%”，足够。

问题：“请判断这家公司的业绩是否大幅改善，并说明理由。” 回答应明确：不能认为大幅改善。最后可补充：“如果只看归母净利润同比+80%会误判，需看扣非”。很好。

需要确保不对“出售子公司获得投资收益1.6亿元”是否全部计入非经常性损益？根据会计准则，处置子公司产生的投资收益通常属于非经常性损益。A股披露扣非会剔除。这没问题。

可以在最终中加入“扣非后利润下降说明公司依靠主营业务创造利润的能力下降，出售资产为一次性收益，未来不持续，甚至可能因出售子公司而减少未来利润来源。” 对。
