应该怎么检验：
1. 先检验两只股票价格序列的单位根（ADF等），确认非平稳。
2. 估计长期关系：P_A = alpha + beta P_B + epsilon，或用对数价格。检验残差平稳性（Engle-Granger协整检验）。残差平稳说明存在长期均衡，价差可能适合配对。
3. 或使用Johansen协整检验。
4. 若协整，进一步看价差的均值回复特征：半衰期（AR(1)系数）、Hurst指数、方差比等；计算Z-score出入场阈值。
5. 样本外检验/滚动协整检验：参数beta和alpha是否稳定，避免过拟合和结构突变。
6. 考虑交易成本、做空可行性、流动性、融券成本、价差交易摩擦；因为高相关但价差标准差小可能收益扣成本不显著。
7. 风险：协整关系可能失效，需设置止损；基本面/事件风险。
8. 经济逻辑：同行业可替代性、基本面驱动相似，但配对交易通常选业务相似、历史价差稳定股票。

检验步骤具体：
- 单位根检验：ADF、PP、KPSS。若价格非平稳，进行协整检验；若平稳则直接价差策略。
- 协整检验：
   - Engle-Granger: OLS回归 ln(P_A) ~ ln(P_B)（或价格水平），得到残差 e_t；检验 e_t 是否平稳。注意临界值不同于标准ADF，需用EG临界值（MacKinnon）。如果残差平稳，说明协整。
   - Johansen test: 向量自回归，检验协整秩。
- 估计对冲比率：如果使用价格水平 P_A = β P_B + e，则做多1股A同时做空β股B，使得组合价值对B价格中性。也可通过回归估计β。如果对数价格，β是市值/数量比例。
- 价差建模：对残差或价差拟合AR(1)，看半衰期 = -ln(2)/ln(phi)（phi为AR(1)系数）是否合理。短半衰期利于交易。
- 形成交易信号：价差Z-score = (价差 - 均值)/标准差；设置入场/出场阈值，如2、0.5，止损3等。但注意参数基于样本内，需样本外验证。
- 样本外/滚动窗口：将3年数据划分训练集和测试集，或滚动估计β和残差均值；检验样本外表现（年化收益、回撤、夏普），扣除交易成本。
- 稳定性检验：用滚动窗口估计β，看是否稳定；若不稳，不建议。
- 检验平均回复非线性：可用Hurst指数<0.5表示均值回复。
- 交易成本影响：考虑双边手续费、冲击成本、融券成本，可能高相关价差波动小，策略净收益不高。
- 其他风险：行业事件导致两者基本面背离、公司特有事件，协整失效。

让我们思考更多细节：

- 配对交易原理：如果两只股票价格存在长期均衡关系，当价差偏离时建立多空组合，期待回归。统计上要求价差平稳/均值回复。
- 协整是必要的：非平稳序列的线性组合平稳。协整检验正是检验这种关系。
- 相关性与协整的区别：
   - 相关衡量两个变量同方向变动程度，不要求平稳。
   - 两个独立的随机游走也可能产生高相关性（伪相关）。
   - 两个高度相关但不存在协整的序列，价差可能是随机游走，不可预测。
   - 两个协整的序列可能相关系数不一定极高，但线性组合平稳。
   - 所以高相关是筛选条件，不是交易依据。
- 同行业股票高相关可能由于共同市场/行业beta，不能保证相对价值回归。

检验步骤详细：
1. 数据准备：用收盘价，通常取对数价格，处理复权、股利、停牌等。3年日线数据样本约750个。
2. 单位根检验：
   - ADF检验原假设存在单位根。
   - 若不能拒绝单位根，则价格非平稳；若拒绝，可能直接考虑价差。
   - 对两个对数价格检验。
3. 协整检验：
   - EG两步法：回归 lnP_A = α + β lnP_B + ε；检验ε的ADF（常数项、无趋势）用MacKinnon临界值。
   - 若ε平稳，协整存在；β为对冲比率（金额/数量需调整）。
   - Johansen检验在VAR框架下更一般，可检验多个协整向量，但对配对通常EG足够。
4. 估计半衰期：
   - 对ε_t拟合AR(1): ε_t = ρ ε_{t-1} + η_t。
   - 半衰期 = -ln(2)/ln(ρ)。若半衰期过短（噪音）或过长（不回归）都不适合。
   - 如果ρ在0.95-0.99可能半衰期约14-69天，需结合成本判断。
5. 交易信号：
   - 计算价差Z-score；设定阈值，如±2开仓，回归0平仓，±3止损。但参数需稳健。
6. 样本外检验：
   - 滚动窗口/前推检验：用过去N天估计α, β, 均值标准差，然后下一期交易；避免使用全样本信息。
   - 计算扣除交易成本后的表现：年化收益率、最大回撤、夏普比率、胜率等。
   - 考虑手续费、滑点、融券成本、保证金、做空限制。
7. 稳健性：
   - 滚动β是否稳定；协整关系可能在重大事件后断裂，需监控。
   - 基本面验证：两家公司业务是否真正可比，是否有并购、重组、财报差异等。
   - 可以引入 Hurst 指数、方差比检验。

开头作答：不可以仅凭0.95的相关系数做配对交易。理由：
- 高相关不等于协整/均值回复。同行业股票受共同市场和行业因素影响，价格同涨同跌，相关系数高但价差可能随机游走。
- 价格序列通常非平稳，高相关可能由共同趋势或伪相关造成；即使收益率相关高，也只是同步，不能保证偏离会回归。
- 配对交易做多一只做空一只，收益来自价差/相对价格的均值回复，而非涨跌方向；必须有统计上平稳的价差/协整关系。
- 高相关可以作为筛候选条件，但须检验。

检验步骤：
1. 数据预处理；2. 单位根检验；3. 协整检验（EG/Johansen）；4. 均值回复检验（AR(1)/半衰期/Hurst）；5. 样本外与滚动验证；6. 交易成本与风险验证；7. 基本面和结构稳定性。
